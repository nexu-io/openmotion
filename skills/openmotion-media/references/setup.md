# Provider discovery and setup

Read for a new generation plan, provider setup or the MCP handbook handoff. Apply the entry's provider preference and spend authorization before submission.

## Media handbook handoff

The MCP handbook media-generation example is an explicit request for multimodal guidance. Start with read-only `inspect` even when the user has yet to supply a concrete asset brief. When a provider is usable under the entitlement guidance below, continue the existing request or ask what they want to generate or which reference they want to recreate. Preserve any reference, brief and project context already supplied.

Follow the setup below and the [job procedure](jobs.md) when generation is needed. Read-only onboarding can proceed without creating a project or starting generation.

## Inspect providers and resolve setup

Call `openmotion_capability_discover` (`action: "list"` / `"describe"` / `"quote"` / `"providers"`) to check live capability definitions, control schemas and spend estimates, or call `openmotion_media_use` with `action: "inspect"` for account entitlement and provider handoff. A provider is usable when `available: true`, except for an OpenDesign account with `mediaEntitlement: "not-included"`. If setup is needed, follow the specific guidance below first. Call the tool and arguments from `settingsHandoff`: signed-out Agents receive `openmotion_media_use` with `action: "sign_in"`; other setup reasons retain `openmotion_open_preview` with `target: "providers"` and its page handoff. Settings remain a fallback for sign-in or checkout failures. Report browser opening only when the result confirms it.

- **Sign-in needed** (`agent_media_signed_out`): call `openmotion_media_use` with `action: "sign_in"` (also for expired sessions). Show `signIn.authorizationUrl` as a clickable link and `signIn.userCode` when present; accurately report `browserOpened`. Then repeatedly call `action: "wait_sign_in"` (default 50 seconds per call, maximum 60) until `ready` or `failed`, for at most 15 minutes overall. Model synchronization still counts as `authorizing`. Do not ask the user to confirm completion in chat. Explain `errorCode` and `connectorInstall` recovery on failure; Settings → Model providers → OpenDesign is a fallback.
- **Free or Go** (`mediaEntitlement: "not-included"`): both plans exclude image, video, speech and music generation. `wait_sign_in` automatically opens the Plus checkout page in the system browser once per account within 30 minutes, using a local one-time sign-in intent that must never be shared. Tell the user whether it opened (`signIn.upgrade.opened`), explain that Plus includes image, video, speech and music generation, and present the credential-free `upgrade.url` as a clickable **Upgrade to Plus / 升级到 Plus** fallback. For an already signed-in Free/Go account, call `action: "open_upgrade"` to open checkout explicitly (each call opens it again), then `wait_sign_in`. Continue waiting for payment automatically; after `ready`, inspect again and resume the original request without asking for payment confirmation in chat. Stop after 15 minutes overall. Plus, Pro and Max include multimodal generation. If checkout cannot open, the existing settings handoff remains available with `entry: "agent_media_upgrade_go"` for Go or `entry: "agent_media_upgrade_free"` for Free; click **Upgrade to Plus** on the OpenDesign page only as a fallback.
- **Rejected key** (`agent_media_key_rejected`): say the saved key was rejected and ask the user to replace it in **Model providers**. The user can also save an OpenDesign Cloud or other supported API key here or supply local media. Cloud keys follow their account's model access and credits. Keep keys in settings.

After `ready`, run `inspect` again and resume the original request. For manually replaced API keys, inspect after setup. A signed-in account (`available: true`) with `mediaEntitlement: "included"` or `"unknown"` can proceed to model discovery, as can other usable providers under the user's preferences and spend consent. The normalized plan and boolean `hasBalance` are advisory when present. Model access and credits are checked when generating. Before generation, state the selected model and cost and obtain consent.

For each needed kind, call `action: "models", provider, modality, refresh: true`. Audio discovery uses `text-to-speech` for speech and `text-to-audio` for music or sound effects. If a needed kind is unavailable, explain the missing part and offer a suitable alternative in the consent question. Continue independent work and avoid switching paid providers or dropping requested capabilities without consent.
